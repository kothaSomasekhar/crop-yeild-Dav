# 🌾 India Crop Analytics — Data Analytics & Visualization Web App

A full-stack data analytics application for Indian crop production data (1997–2015),
built with **Python · Pandas · Scikit-learn · Plotly · Seaborn · Streamlit · Joblib**.

---

## 📁 Project Structure

```
crop-yeild/
├── data/
│   ├── crops.csv            ← Raw dataset (246 k rows × 7 cols)
│   ├── clean.csv            ← Cleaned data (generated by train.py)
│   ├── metrics.csv          ← Model evaluation metrics (generated by train.py)
│   └── india_states.geojson ← GeoJSON downloaded on first app launch
├── models/
│   ├── linear_regression.pkl
│   ├── random_forest.pkl
│   ├── preprocessor.pkl
│   └── meta.pkl
├── train.py    ← Step 1: preprocessing + model training
├── app.py      ← Step 2: Streamlit multi-page web app
├── requirements.txt
└── README.md
```

---

## ⚙️ Setup

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train models (must be done before launching the app)
python train.py

# 3. Launch the app
streamlit run app.py
```

The app will open automatically at **http://localhost:8501**.

## 🔧 Stage 1 — `train.py`

**What it does:**
1. **Load** raw `data/crops.csv`
2. **Wrangle**: strip/title-case text fields, fix dtypes, remove duplicates
3. **Create Yield**: `Production / Area` (drops rows where Area ≤ 0 or Production is missing)
4. **Cap outliers** on `Area`, `Production`, `Yield` using the IQR method (1.5×IQR)
5. **Save** `data/clean.csv`
6. **Feature engineering**: categorical OHE (`State_Name`, `Crop`, `Season`) + StandardScaler on (`Area`, `Crop_Year`)
7. **Train** Linear Regression and Random Forest (200 trees) in sklearn Pipelines
8. **Evaluate** RMSE, MAE, R² on 20 % test set + 5-fold cross-validation R²
9. **Save** models (`models/*.pkl`), preprocessor, metadata, and `data/metrics.csv`

## 📊 Stage 2 — `app.py` (Streamlit Pages)

| Page | Contents |
|---|---|
| **Overview** | Dataset summary, missing-value bar chart, raw vs clean row counts, stats tables |
| **EDA** | Yield histogram, box plot by season, correlation heatmap, top-10 states bar, yield trend by year, Plotly choropleth of avg yield by state |
| **Model Comparison** | Metrics table, RMSE/R² bar charts, actual-vs-predicted scatter, RF feature importance |
| **Predict** | Input form → predicted yield from both models + gauge chart |

Sidebar filters (State, Crop, Season) narrow down all EDA charts simultaneously.

---

## 🌟 Key Design Decisions

- **Pipeline prevents data leakage**: preprocessing is fit only on training data.
- **`handle_unknown='ignore'` in OHE**: app won't crash on unseen categories at prediction time.
- **IQR capping** (not removal): keeps real diversity while eliminating extreme data-entry errors.
- **GeoJSON cached locally**: downloaded once from a public GitHub repo; subsequent launches use the local file.
- **`@st.cache_resource` for models**: large objects stay in memory across user sessions.
